# Package Scripts Menu

Запускайте команды из `package.json` кнопками прямо в VS Code.

## Установка

Нажмите **Install / Установить** на странице расширения в VS Code.

## Как пользоваться

Откройте `package.json` — рядом появится меню команд. Нажмите **Запустить**, чтобы выполнить команду. Вывод появится во встроенном терминале.

- **☆** — добавить команду в избранное.
- **Часто запускаемые** — команды, которыми вы пользуетесь чаще всего.
- **ⓘ** — показать полную команду при наведении.
- **Остановить** — отправить Ctrl+C и подождать завершения; по умолчанию до 30 секунд перед принудительной остановкой.

Избранное и частота запусков сохраняются отдельно для каждого репозитория и `package.json`.

Поддерживаются **npm, pnpm, yarn и bun**. Для запуска нужны Node.js и выбранный менеджер пакетов.
